# 文档格式整理工具 - 多格式支持

这是一个专业的文档格式整理工具，支持将混乱的docx文件转换为符合规范的格式化DOCX文档或Markdown文档。

## 功能特点

- 📄 **智能内容提取**: 自动从源docx文件中提取面试题和答案内容
- 🎨 **多格式支持**: 支持生成格式化的DOCX和Markdown两种格式
- 📋 **完整文档结构**: DOCX格式自动生成封面页、修订记录表、目录页
- 🎯 **统一样式**: 确保所有文本使用一致的字体和格式
- 📝 **智能分类**: 自动识别题目、答案、章节标题等不同内容类型
- 🚀 **批量处理**: 支持批量处理多个docx文件
- 📐 **规范排版**: DOCX格式支持A4纸张、标准页边距、1.5倍行距、首行缩进
- 🔗 **自动目录**: Markdown格式自动生成可点击的目录链接

## 生成的文档结构

每个格式化后的文档包含：

1. **封面页**
   - 文档标题
   - 版本信息
   - 作者信息
   - 部门信息
   - 更新日期

2. **修订记录表**
   - 日期、版本、修改人、修改描述

3. **目录页**
   - 文档目录结构

4. **格式化正文**
   - 章节标题（黑体，三号）
   - 问题标题（黑体，四号）
   - 答案标题（黑体，小四号）
   - 答案内容（微软雅黑，小四号）

## 环境要求

- Python 3.7+
- Windows系统
- 无需外部LLM服务

## 快速开始

### 1. 环境安装

运行提供的安装脚本：

```bash
setup_env.bat
```

该脚本会：
- 创建Python虚拟环境
- 安装所有依赖包

### 2. 准备文件

将要整理的docx文件放入 `source` 目录：

```
docFormatlyFlow/
├── source/
│   ├── AI面试题.docx
│   └── JAVA基础.docx
├── target/          # 输出目录
└── bat/             # 批处理脚本目录
```

### 3. 运行程序

激活虚拟环境后运行：

**方法1：使用批处理文件（推荐）**
```bash
.\bat\run_md.bat
```
然后选择需要的格式：
- 选项1：生成格式化的DOCX文件
- 选项2：生成Markdown文件
- 选项3：同时生成两种格式

**方法2：直接运行Python脚本**
```bash
# 如果使用conda
conda activate docformatter

# 如果使用venv
venv\Scripts\activate.bat

# 生成DOCX格式
python docx_formatter.py

# 或生成Markdown格式
python doc_formatter_to_md.py
```

### 4. 查看结果

生成的文件将保存在 `target` 目录中：
- DOCX文件：专业的文档格式，包含封面页、修订记录等
- Markdown文件：轻量级文本格式，便于在线查看和版本控制

## 样式规范

### 页面设置
- 纸张大小：A4 (21.0 × 29.7 厘米)
- 页边距：上下左右均为2.54厘米
- 行距：1.5倍
- 段落格式：两端对齐，首行缩进2字符

### 字体规范
- **默认字体**: 微软雅黑，小四号(12pt)
- **一级标题**: 黑体，三号(16pt)
- **二级标题**: 黑体，四号(14pt)
- **三级标题**: 黑体，小四号(12pt)
- **答案标题**: 黑体，小四号(12pt)，加粗
- **答案内容**: 微软雅黑，小四号(12pt)

### 中英文字体兼容
程序确保中英文都使用正确的字体设置，避免出现字体不一致的问题。

## 故障排除

### 依赖安装失败
- 检查网络连接
- 使用国内镜像源: `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt`

### 文件处理失败
- 确保docx文件格式正确
- 检查文件权限
- 查看日志输出

### 字体显示异常
- 确保系统安装了黑体和微软雅黑字体
- 检查Office版本兼容性

## 注意事项

- 程序会自动创建target目录
- 处理大文件时可能需要较长时间
- 建议备份原始文件
- 程序会自动清理文本中的乱码字符
